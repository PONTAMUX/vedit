## 既知の差(第2部終了時)
- 文字の太さ/字形は Qt と Chromium で多少違う。
- 音量・ミュート・倍速・BGM/効果音のミックス再生は AudioPlayer に実装済み(null シンクでのみ検査、実機の聞き比べは未実施)。処理後/生の音の切替(c-proc)は null シンクで検査済み。メーターは実際の出力レベル(vedit-gl-test で null シンク検査)。
- 修正点パネルの修正前映像は QMediaPlayer(Windows の Qt Multimedia)の描画で、本編のような GPU 直描きではない。長いシークは keyframe 0.5 秒の軽量版に頼る。
- 波形は wave.json(無ければ Python の wave ジョブで作る)。ネイティブ計算は無し。
- プレビューの即時反映は vedit-gl-test(窓なし GL)で検査済み。実窓での体感は未確認。
